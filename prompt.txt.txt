To draw a line on a grid of text characters, we use a classic graphics algorithm called Bresenham's Line Algorithm. It calculates the closest pixel steps without needing slow floating-point math.
Once you have a working drawLine, making a rectangle becomes incredibly easy because you can just draw 4 individual lines.

void drawLine(int x1, int y1, int x2, int y2) {
    int dx = abs(x2 - x1);
    int dy = abs(y2 - y1);
    int sx = (x1 < x2) ? 1 : -1;
    int sy = (y1 < y2) ? 1 : -1;
    int err = dx - dy;

    while (1) {
        setPixel(x1, y1); // Draw the current pixel

        // If we reached the end point, stop
        if (x1 == x2 && y1 == y2) {
            break;
        }

        int e2 = 2 * err;
        if (e2 > -dy) {
            err -= dy;
            x1 += sx;
        }
        if (e2 < dx) {
            err += dx;
            y1 += sy;
        }
    }
}
void drawRectangle(int x1, int y1, int x2, int y2) {
    // Top side
    drawLine(x1, y1, x2, y1);
    // Bottom side
    drawLine(x1, y2, x2, y2);
    // Left side
    drawLine(x1, y1, x1, y2);
    // Right side
    drawLine(x2, y1, x2, y2);
}

The Bugs Identified
1. The Rectangle Bug (drawRectangle)
The Issue: For the bottom line, you wrote drawLine(x2, y2 - 1, x1, y2 - 1);. Subtracting 1 from the Y coordinate shifts the bottom border up by one pixel, leaving the actual bottom open.

The Issue: In the Y coordinate math, you used (radius - 1) * sin(rad). Because the X radius and Y radius don't match, your circle draws as an asymmetric, slightly flat ellipse.
The Fix: Change radius - 1 to just radius.

3. The Triangle Bug (drawTriangle)

        else if(choice == 0) {
            printf("Exiting...
");
            break;
        }
        else {
            printf("Invalid choice!
");
        }
    }

    return 0;
}
