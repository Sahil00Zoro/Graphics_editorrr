# 2D Graphics Editor

## Description

This project is a simple 2D Graphics Editor developed in C using a 2D character array. It allows users to create and edit basic graphical objects on a text-based canvas.

## Features

* Draw Lines
* Draw Rectangles
* Draw Circles
* Draw Triangles
* Add Objects
* Delete Objects
* Modify Objects
* Display the Canvas
* Clear the Canvas

## Data Structure Used

The program uses a 2D character array:

char picture[HEIGHT][WIDTH];

to store and display graphical objects.

## How to Compile

gcc graphics_editor.c -o graphics_editor -lm

## How to Run

./graphics_editor

## Menu Options

1. Draw Line
2. Draw Rectangle
3. Draw Circle
4. Draw Triangle
5. Display Picture
6. Add Object
7. Delete Object
8. Modify Object
9. Clear Picture
10. Exit
